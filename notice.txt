This script will deploy VLESS and proxies using Sing-Box
and it requires the following in order to proceed:

1. A Cloudflare account

2. A Cloudflare API key that has permission to edit the following Zones [DNS, SSL and Certificates]

3. A domain name added to your Cloudflare account with a subdomain with 'A' record pointed to your origin server to use for protocols that are compatible with CDNs
        such as [Websocket, gRPC]
